# Конфигуратор водоотвода

Одностраничное приложение для подбора линейного водоотвода из нержавеющей стали. Пользователь выбирает объект, задаёт трассу и количество воды, а приложение подбирает серию канала, решётку и выпуски, рисует чертёж и считает смету.

## Что умеет

- 5 шагов: где ставим, трасса, сколько воды, исполнение, монтаж и доставка
- подбор серии канала по расходу воды, глубине и пропускной способности трапов, по умолчанию берётся самая дешёвая подходящая
- решётки, которые не держат нагрузку объекта, недоступны, причина написана прямо в карточке
- чертёж плана трассы с размерами, секциями, уклоном и выпусками, разрез канала у выпуска
- обводка своей трассы по картинке: загружаешь план, задаёшь масштаб по известному отрезку, кликаешь точки
- вид канала в полу сверху: фото покрытия, канал и решётка поверх в масштабе
- сравнение серий: узкий канал дешевле за метр, но просит больше выпусков
- спецификация с пометкой, откуда взята цена
- заявка менеджеру уходит в мок (`POST /leads`)
- всё состояние лежит в адресе, ссылкой на расчёт можно поделиться

Скачивание PDF, DXF и Excel, отправка в мессенджер, на почту и КП для подрядчика пока заглушки в меню. Для них нужен бэкенд.

## Стек

React 19, TypeScript, Vite, Ant Design 6, json-server как мок API, Vitest.

## Запуск

```bash
npm install
npm run dev
```

Откроется http://localhost:5173. Команда поднимает сразу два процесса: json-server на порту 3001 и Vite. Vite проксирует `/api` на json-server.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | мок и фронт вместе |
| `npm run mock` | только мок на 3001 |
| `npm run web` | только фронт |
| `npm test` | тесты движка |
| `npm run typecheck` | проверка типов |
| `npm run build` | сборка в `dist` |

## Данные

Все данные лежат в `mock/db.json`:

| Ручка | Что внутри |
| --- | --- |
| `GET /objects` | типы объектов: класс нагрузки, минимальное сечение, решётка и сталь по умолчанию |
| `GET /series` | серии каналов: размеры и цена за метр |
| `GET /grates` | решётки: класс нагрузки и цена по ширине сечения |
| `GET /parts` | комплектующие: углы, тройники, стыки, пескоуловители |
| `GET /works` | монтаж и доставка |
| `GET /traps` | трапы: размер, DN, пропускная способность, цена |
| `GET /surfaces`, `/classes`, `/floors` | покрытия, классы нагрузки, фото полов |
| `GET /settings` | правила расчёта и коэффициенты |
| `POST /leads` | заявки |

Цены можно править прямо в файле, json-server подхватит изменения сам. Заявки он тоже пишет в этот файл, так что перед коммитом их лучше убрать.

Чтобы подключить настоящий бэкенд, достаточно задать `VITE_API_URL`, весь фронт ходит в API через `src/api/client.ts`.

## Как устроено

```
src/
  engine/       расчёт: чистые функции без React
    geometry.ts   трасса, прогоны, раскладка выпусков
    plan.ts       вода, гидравлика, подбор серии, смета
    state.ts      состояние, правила смены полей, адрес
    summary.ts    строки штампа и заявки
  drawing/      раскладка чертежа плана
  hooks/        useConfigurator: состояние + расчёт + адрес
  components/   интерфейс на Ant Design
```

Порядок расчёта:

1. Из формы трассы и длин получаем прогоны, торцы, углы и тройники.
2. Считаем расход воды: дождь с площади `Q = psi * q20 * F` или сумма точек слива.
3. Для каждой подходящей серии считаем, сколько нужно выпусков. Ограничений три: глубина (с уклоном канал углубляется к выпуску), пропускная способность трапа и пропускная способность самого канала (Маннинг для уклона, свободный излив без уклона).
4. Подбираем трапы и считаем смету. Самая дешёвая серия становится выбранной, остальные идут в сравнение.

Подписи на чертеже не должны налезать друг на друга и на канал. Шрифт на листе моноширинный, поэтому размер подписи считается по числу символов, и раскладка обходится без замеров в DOM.

## Тесты

```bash
npm test
```

Юнит-тесты движка и 14 эталонных расчётов в `src/engine/__tests__/golden.json`: для каждого сценария проверяются выбранная серия, число выпусков, высоты канала, все строки сметы и итог.

## Допущения

Цены демонстрационные. Нормативы, на которые опирается расчёт: СП 32.13330 (дождевой сток), СП 30.13330 (расход точек слива), ГОСТ 32955 и EN 1433 (классы нагрузки решёток).
